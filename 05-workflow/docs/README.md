## À quoi sert ce dossier

Les procédures que l'équipe consulte au quotidien, et que le nouveau recruté lira pendant sa première semaine. Le sujet les exige : « Les différentes procédures rédigées pour les utilisateurs. »

| Fiche 5, réagir à une alerte | Équipe plateforme |
| Journal des incidents | Toute l'équipe |
| Compte rendu des tests de restauration mensuels | Équipe plateforme |

Les cinq fiches sont déjà rédigées dans `../../03-cahier-specifications-techniques/sections/G-procedures-bpmn.md`, partie G.7. Il s'agit de les extraire ici, dans un format consultable rapidement, et de les tenir à jour quand le workflow évolue.

## Pourquoi ce dossier compte pour la note

La partie I du cahier des spécifications techniques montre que la rentabilité du workflow s'effondre si une seule personne sait s'en servir. Cette documentation est ce qui empêche ce scénario.
