# Maquettes

**Responsable** : R4, relu par R1.
**Échéance** : 22 août.

## Ce que le sujet exige

Les mêmes trois pages, dans les mêmes trois formats, soit neuf vues, cette fois avec l'identité visuelle complète.

## État actuel

Le fichier Figma du projet contient la page d'accueil en cinq largeurs : 1920, 1512, 1440, 768 et 390 px. Elle a été générée à partir de l'intégration front, ce qui garantit que la maquette et le site sont identiques.

Il manque les deux autres pages : connexion et inscription, et le profil client. Les deux existent déjà dans le code, aux adresses `/connexion`, `/inscription` et `/mon-compte`.

## Méthode retenue, et pourquoi elle se défend

Les maquettes sont produites à partir de l'intégration, pas l'inverse. C'est inhabituel, et c'est un argument en soutenance : quand le jury demandera si les maquettes correspondent au site livré, la réponse est qu'elles en sont issues, donc l'écart est nul par construction.

Pour les zonings et les wireframes, la même logique s'applique : une route de travail non indexée rend les mêmes pages en mode zoning ou en mode wireframe, et les captures suivent. Trois artefacts cohérents entre eux, produits en une demi-journée au lieu de trois jours de redessin.

## Nommage

`maquette-{page}-{format}.png`.
