## Ce qui est déjà fait

Les couleurs sont posées et vérifiées dans le code, fichier `../../06-app/theetiptop-contest/apps/web/src/app/global.css`. Les ratios de contraste ont été calculés avant de figer les valeurs.

Un point à faire figurer explicitement dans la charte, parce qu'il montre le raisonnement : le laiton clair tombe à 2,42 sur le fond papier, il est donc inutilisable pour du texte. Une variante plus sombre à 7,00 lui est substituée dès qu'il s'agit de texte, le laiton clair restant réservé aux surfaces décoratives.
