# Mesure d'audience

**Responsable** : R2, intégration technique par R3.
**Échéance** : 30 septembre pour le compte, 8 novembre pour la configuration complète.

## Ce que le sujet exige

> « Dans le cadre du projet, vous devrez obligatoirement créer un compte Google Analytics et le lier à votre site internet. Vous devrez sur ce compte avoir personnalisé le dashboard en fonction de vos objectifs mais également prévoir : un événement pour voir le nombre de vues sur une page donnée, un événement pour la soumission d'un formulaire, un événement pour suivre les clics sur un CTA, un événement pour l'ajout au panier ou la réservation, la mise en place d'un rapport personnalisé. »

## Les quatre événements, transposés au projet

| Événement demandé | Transposition |
|---|---|
| Vues d'une page donnée | Page des lots à gagner |
| Soumission d'un formulaire | Création de compte |
| Clic sur un CTA | Bouton « Saisir mon code » |
| Ajout au panier ou réservation | Participation, c'est-à-dire la validation d'un code |

Le sujet écrit « selon le sujet » pour ce dernier point : il n'y a ni panier ni réservation ici, la participation est l'action de conversion équivalente. Ce raisonnement doit figurer dans le dossier, il sera peut-être demandé à l'oral.

## Ce qui doit vivre ici

| Fichier | Contenu |
|---|---|
| `configuration.md` | Le paramétrage du compte, propriété, flux, conservation des données |
| `evenements.md` | Les quatre événements, leur déclencheur et leur paramétrage |
| `rapport-personnalise.md` | Le rapport créé, ses dimensions et ses métriques |
| `kpi.md` | Les indicateurs par action, exigés en partie D.6 du cahier des charges |
| `captures/` | Captures du tableau de bord et du rapport, pour le dossier |
| `acces.md` | Identifiants, à reporter dans le document d'accès du 16 novembre |

## Contrainte légale

Le sujet demande d'indiquer « les éventuelles contraintes légales à prendre en compte en fonction des outils utilisés, cookies, opt-in ». La mesure d'audience n'est déclenchée qu'après consentement, via le bandeau cookies déjà présent sur le site.
