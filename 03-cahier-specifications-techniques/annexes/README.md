# Annexes du cahier des spécifications techniques

**Responsable** : R1, relu par R3.

## Ce qui est obligatoire

Le sujet est explicite : « A minima, les annexes doivent comporter le calcul du TJM des ressources du projet. »

Le calcul est déjà rédigé dans `../../02-cahier-des-charges/annexes/calcul-tjm.md`. Il est commun aux deux dossiers, il faut donc l'insérer aussi dans celui-ci. Ne pas en faire deux versions divergentes : c'est le même fichier source, inséré deux fois.

## Ce qu'on peut y ajouter

- La base de calcul détaillée des coûts d'hébergement, avec les grilles tarifaires des prestataires
- Les relevés de mesure ayant servi à l'estimation des pertes actuelles, partie I.3
- La source citée pour la grille de salaire de la fiche de poste, partie F.1
- Toute étude ayant servi aux choix techniques de la partie D.2

## Point de vigilance

Le sujet insiste : « Il faudra mettre en annexes de ce dossier la base de calcul utilisée pour le taux horaires des ressources et donc tous les calculs effectués. Cela permettra de voir qu'il n'y a pas d'erreur sur l'estimation du coût du projet. »

Autrement dit, les calculs doivent être vérifiables ligne à ligne, pas seulement leur résultat.
